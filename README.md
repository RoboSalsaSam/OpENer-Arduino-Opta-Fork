OpENer Arduino Port Version - 0.1
==================================

The OptaEtherNetIP is based on OpENer and was adapted mainly via AI and not made by an expert

To use this find "source\src\ports\Arduino\Arduino EtherNetIP" this folder can be used as a normal Arduino library it also contains an example sketch
The library also contains useful docs as to what was modified and what files where copied.
This version has only been tested on an arduino opta and not all functions have been tested.
